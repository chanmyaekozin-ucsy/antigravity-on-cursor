Quick SSH Tunnel Setup

If you have a VPS or server outside your region, this is the easiest way to create a proxy:

1
Start SOCKS5 tunnel (runs in background):
ssh -D 1080 -N -f user@YOUR_SERVER_IP
2
Enter this as your Proxy URL above:
socks5://127.0.0.1:1080
3
Click Save then Apply PAC to macOS above.
